## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Aryanbhayji/selenium-module.git
```

### 2️⃣ Navigate to the project folder

```bash
cd selenium-module
```

### 3️⃣ Install Selenium

```bash
pip install selenium
```

### 4️⃣ Run the project

```bash
python main.py
```
